# Mentra

Mentra is a topic-driven tutoring platform: type a topic (or snap a photo of a homework
problem) and get a full learning package — a structured lesson, a quiz that re-explains
wrong answers in a new modality, an FSRS-scheduled flashcard deck, exact video timestamps,
and ranked tutors — generated by a multi-agent LangGraph pipeline grounded in the outside
world through MCP servers. A peer layer surfaces (with consent) what your connections are
struggling with, and proposes study squads when enough of them hit the same wall.

Full design rationale lives in the original technical design doc; this README covers what's
actually in this scaffold, how to run it, and how to exercise every demoable flow.

## Scaffold depth

This build is a **structural skeleton**: every layer runs for real end-to-end, but the pieces
that would call the Claude API (intent parsing, lesson/quiz generation, snap-a-problem vision)
are deterministic stubs that return realistically-shaped content — no `ANTHROPIC_API_KEY`
required to run the full pipeline. Everything that's a deterministic algorithm rather than an
LLM call is implemented for real:

- Prerequisite-graph traversal and gap redirection (`backend/app/orchestrator/nodes/prerequisite_graph.py`)
- FSRS flashcard scheduling (`backend/app/fsrs/scheduler.py`)
- Mastery scoring and struggle-signal emission (`backend/app/orchestrator/nodes/mastery_scorer.py`)
- Peer struggle-feed aggregation and study-squad formation (`backend/app/peer/engine.py`)
- All four MCP servers (video transcript search, tutor matching, calendar booking with a real
  15-minute hold, and nearby-tutor geo search) run as real MCP protocol servers over
  streamable-HTTP, queried by the orchestrator as a real MCP client — no simulated tool calls.

Embeddings (topic, transcript, tutor) use a deterministic placeholder function
(`pseudo_embed`, duplicated in each service that needs it) instead of a real embedding model,
so pgvector similarity search is exercised end-to-end without an external API dependency. Swap
it for Claude embeddings / sentence-transformers when you're ready.

## Architecture

```
frontend (React/Vite)  →  backend (FastAPI + WebSocket)  →  Celery worker
                                                                  │
                                                     LangGraph StateGraph
                                                    (backend/app/orchestrator)
                                                                  │
                                          ┌───────────────────────┼───────────────────────┐
                                    intent_parser          prerequisite_graph        lesson_generator
                                          │                                                │
                                    quiz_agent  →  flashcard_agent  →  [video_curator, tutor_matcher, mastery_scorer]  →  stream_result
                                                                              │                  │
                                                                      Video MCP server     Tutor Match MCP server
                                                                                            Calendar/Booking MCP server
                                                                                            Maps/Places MCP server

Postgres + pgvector: topics, lessons, flashcards, tutors, bookings, struggle events, connections
Redis: Celery broker/backend + WebSocket pub/sub fan-out
```

Every graph-node completion is published to a per-session Redis channel and forwarded to the
browser over WebSocket, so the lesson renders while the quiz/flashcards/videos/tutors are
still generating in parallel (`backend/app/tasks.py`, `frontend/src/api/ws.ts`).

## In scope vs. deferred

**In scope (this build):** FSRS spaced repetition, prerequisite-graph gap tracing, quiz
modality re-explanation, confidence tagging, snap-a-problem input, timestamp-level video
search, tutor matching + filters + real-time booking holds, the peer struggle feed, study
squads, topic Q&A with moderation, and mentor-track profiles.

**Deferred (future work):** LMS integration (Canvas / Google Classroom), a parent/teacher
dashboard, real tutor background-check verification, and payments/dispute handling — each
needs a third-party integration or compliance review this build doesn't include. Booking ends
at a confirmed calendar hold; no money moves.

## Setup

Prerequisites: Docker, Python 3.11+, Node 20+.

```bash
cp .env.example .env

# 1. Infra
make up                 # Postgres (pgvector) + Redis via docker compose

# 2. Backend deps
cd backend && python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cd ..

# 3. Schema + seed data
make seed                # creates tables, seeds topics/tutors/videos/connections/struggle events

# 4. MCP servers (each in its own venv, or share the backend's)
cd mcp_servers/video_transcript && pip install -r requirements.txt && cd ../..
cd mcp_servers/tutor_match && pip install -r requirements.txt && cd ../..
cd mcp_servers/calendar_booking && pip install -r requirements.txt && cd ../..
cd mcp_servers/maps_places && pip install -r requirements.txt && cd ../..
make mcp                 # starts all four on ports 8101-8104

# 5. Backend + worker (separate terminals)
make backend              # uvicorn on :8000
make worker                # celery worker

# 6. Frontend
cd frontend && npm install && cd ..
make frontend              # vite dev server on :5173
```

Open `http://localhost:5173`.

## Demo walkthrough

1. **Prerequisite gap redirect.** On the Learn page, the seeded learner `u_amy` is weak on
   "limits" (mastery 0.2). Type `derivatives` and generate a lesson — the pipeline redirects
   the lesson target to "limits" and shows the redirect banner (`prerequisite_graph_node`,
   Section 4.2). Switch the learner selector to `u_ben` and try again — no redirect, since
   `u_ben` has no recorded mastery gap.

2. **Quiz modality re-explanation.** The generated quiz always seeds one simulated miss on the
   first question to demonstrate the escalation order for real: analogy → diagram → video. The
   video slot is filled in live once the Video Curator node's real MCP call to the transcript
   server returns (Section 4.5).

3. **Flashcards + FSRS.** Rate your confidence (0-5) before revealing each card's answer, then
   mark it recalled or missed — this calls `/learn/confidence`, which runs the real FSRS update
   and reschedules the card's due date.

4. **Struggle feed + study squad.** Go to Peer Feed as `u_amy` — you'll see struggle signals
   from connected learners `u_ben` and `u_cara`, both seeded with a "derivatives" quiz-miss
   event. Because all three are mutually connected and struggling on the same topic, a study
   squad is proposed (`propose_squads_for_topic`, Section 7.3).

5. **Tutor booking hold.** On the Tutor Hub, search "derivatives" — results come from a real
   MCP call to the Tutor Match server (pgvector similarity + verification tier + price/format
   filters). Click a tutor, pick an open slot — this calls the Calendar MCP server's
   `create_booking_hold`, which writes a real row with a 15-minute expiry and rejects a
   conflicting second hold on the same slot.
